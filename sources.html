CaesiumOS (Conception)

The source code of the CaesiumOS (Conception) project is hosted on GitHub under the 'CaesiumOS' organization.
Conception is the codename of both CaesiumOS 4.x and the latest Lineage-based CaesiumOS source rebase, undertaken in late April 2026.

Check out the CaesiumOS (Conception) source

jpbROM

The source code of the jpbROM project is hosted on GitHub under the 'jpbROM' organization.
jpbROM is the original name of CaesiumOS, with it having been retained in versions based on Android 14 and below.

Check out the jpbROM source
